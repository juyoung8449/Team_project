# 화랑과 함께하는 각궁 만들기

프로젝트 폴더에서 `python3 -m http.server 8000`을 실행하고 브라우저에서
`http://localhost:8000/`을 엽니다. Three.js CDN을 불러올 인터넷 연결과 WebGL 지원이 필요합니다.

게임은 같은 공방에서 제작 14단계를 거친 뒤 활쏘기와 입단식으로 이어집니다.
각 단계의 시작 안내에서 **확인**을 누르면 단계의 연출과 조작이 시작됩니다.
왼쪽 진척도에서 14단계와 현재 단계를 확인할 수 있습니다.
작은 화면에서는 안내창과 일부 상태 영역을 스크롤해 내용을 확인할 수 있습니다.
반투명 손의 안내에 따라 드래그하거나 터치하면 안내가 사라집니다.
2단계에서는 대나무의 표시된 부분을 불꽃의 원 안에서 좌우로 움직입니다.
손을 떼거나 불에서 벗어나도 미달 가열 시간은 유지되며, 다시 잡으면 이어서 가열합니다.
각 부분을 8~12초 가열한 뒤 손을 떼거나 **불에서 빼기**를 누르면 판정합니다.
버튼으로 일찍 판정하면 실패하며, **다시하기**는 두 부분을 처음부터 초기화합니다.
두 부분이 완성되면 대나무가 따뜻한 아이보리·황토색으로 식습니다.
4단계는 연타 안내에 맞춰 10초 안에 50번 터치하고, 5단계에서는 천연풀을 고릅니다.
6단계에서는 가이드 원이나 빈 작업 화면에서 한 방향으로 약 4.5바퀴 드래그해 밧줄을 감습니다.
제작 성공과 활쏘기 점수에 따라 칭찬 스티커가 나타납니다.
활쏘기는 과녁을 향해 누르고 있다가
힘 게이지가 55~85%일 때 놓습니다. 후반 공방의 처음으로 버튼은 게임을 처음부터 다시 시작합니다.

`index.html`이 진입점이며 `scene.js`가 하나의 3D 장면과 렌더링 루프를 관리합니다.
`stage-ui.js`는 공통 단계 안내와 진척도, 칭찬 연출을 관리합니다.
`game-state.js`와 `script.js`는 앞의 여섯 단계의 상태와 조작을 담당하고,
`continuation.js`는 `taerim/`의 공방, 캐릭터, 후반 제작 및 엔딩을 같은 장면에 연결합니다.
